# YouTube API Documentation (LLMs)
> Canonical entry points and references for YouTube APIs (Data, Live, Analytics/Reporting, Content ID, and Player).

These links cover the public YouTube APIs most developers use: the YouTube Data API v3 (including Live Streaming features), Analytics and Reporting APIs for channel metrics, the partner‑only Content ID API, and the IFrame Player API for playback. Authentication and authorization are handled via Google OAuth 2.0, while API keys are used for simple public‑data requests. Use the API reference pages for endpoint details and the guides for workflows, quotas, and error handling.

## Core APIs
- [YouTube Data API Overview](https://developers.google.com/youtube/v3): Product overview and general entry point.
- [YouTube Data API Reference](https://developers.google.com/youtube/v3/docs): Endpoint reference for all resources and methods.
- [Getting Started](https://developers.google.com/youtube/v3/getting-started): Quickstart and basic setup.
- [Implementation Guide](https://developers.google.com/youtube/v3/guides/implementation): Architectural guidance and common patterns.
- [Using OAuth 2.0](https://developers.google.com/youtube/v3/guides/authentication): User authorization flows and scopes.
- [API Errors](https://developers.google.com/youtube/v3/docs/errors): Error formats and troubleshooting guidance.
- [Quota Calculator](https://developers.google.com/youtube/v3/determine_quota_cost): Quota units and cost estimation.
